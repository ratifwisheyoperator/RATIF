# RATIF - Patient Management System

A simple Python project for managing patient records.

## Files in this Repository
- `ratif.py` - Main Python program
- `patients.json` - Database file storing patient data in JSON format

## What it Does
This program helps to:
- Add new patients
- Store patient information
- View patient records
- Manage data using JSON

## Tools Used
- Python 3
- JSON for data storage
- GitHub for version control

## How to Run
1. Make sure Python is installed
2. Run: `python ratif.py`
3. Follow the menu options
